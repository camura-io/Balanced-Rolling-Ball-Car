# 车载平衡滚球运动控制系统 (2026年山东省电赛H题)

本项目为 2026 年山东省大学生电子设计竞赛 H 题（车载平衡滚球运动控制系统）的完整工程代码。
整个系统分为三个部分，分别对应三块核心板：

## 📁 目录结构

### 1. [LineTracking (寻迹底盘)](LineTracking/README.md)
* **主控**：STM32F103 (标准库)
* **功能**：底盘移动控制。读取 8 路红外循迹传感器，通过加权偏差和分段 PD 算法实现自动循迹；带起步/刹车斜坡调速，并在起步和减速时通过 2 个 GPIO 给平衡板发信号。
* 📝 [查看寻迹部分详细说明](LineTracking/README.md)

### 2. [BalancingJoystick (平衡与主控)](BalancingJoystick/README.md)
* **主控**：STM32H750 (CubeMX + HAL 库)
* **功能**：小球平衡控制。串口接收 K230 发送的钢球位置，运行 PID 算法驱动步进电机调节导轨倾角；同时监听底盘的 2 个 GPIO 状态，在底盘加减速时叠加写死的时间衰减前馈步数抵消惯性。
* 📝 [查看平衡部分详细说明](BalancingJoystick/README.md)

### 3. [VisionK230 (视觉识别)](VisionK230/README.md)
* **平台**：嘉楠 CanMV K230 (MicroPython)
* **功能**：摄像头实时检测钢球。运行 YOLO11 目标检测模型，通过 5 点分段线性插值把像素坐标换算成实际毫米距离，以 40Hz 频率串口发送给 H750。
* 📝 [查看视觉部分详细说明](VisionK230/README.md)

## ⚙️ 系统协作流程

1. **视觉定位**：K230 摄像头采集画面，通过 YOLO11 模型检测小球位置，结合现场 5 点标定计算出小球相对导轨中心的实际毫米距离，以 40Hz 串口发送给 STM32H750。
2. **平衡控制**：STM32H750 作为主控，根据小球位置误差做 PID 计算，输出 STEP/DIR 脉冲控制步进电机调节导轨角度；同时读取 F103 发来的 2 路 IO 信号，在起步和刹车瞬间叠加前馈步数，防止小球被惯性甩飞。
3. **底盘循迹**：STM32F103 独立读取 8 路红外传感器，通过加权偏差与分段 PD 差速控制底盘循迹；在起步加速和到达终点减速时翻转 IO 引脚电平，通知平衡板做前馈。
