# 视觉识别部分 (VisionK230)

## 1. 模块简介
负责导轨中小球的实时视觉识别与定位，硬件基于嘉楠 CanMV K230（双核 64 位 RISC-V，集成 KPU 神经网络加速器），软件基于 MicroPython 和 PipeLine 视频流框架。

## 2. 硬件与环境
* **主控板**：01Studio CanMV K230 / K230 Mini。
* **摄像头**：CSI0 接口高清摄像头。
* **屏幕**：3.5 寸 MIPI LCD（ST7701 驱动，800×480 分辨率），实时显示摄像头画面、检测框和标定辅助线。
* **通信接口**：UART1（引脚 3=TXD, 4=RXD，波特率 115200）连接 STM32H750。

## 3. 检测算法与坐标标定

### 3.1 YOLO11 目标检测
* 采集钢球在不同光照和背景下的图片，在 PC 端训练轻量化 YOLO11 模型，量化导出为 KPU 专用的 `yolo11n_det_320.kmodel`，模型输入尺寸 320×320。
* 设置置信度阈值 0.6、NMS 阈值 0.45，自动过滤误检和反光，提取置信度最高的目标中心坐标 (cx, cy)。

### 3.2 5 点分段线性标定
由于摄像头俯视导轨存在透视和广角畸变，不能用固定的像素比例直接折算距离。
* 在导轨上选取 5 个已知距离的参考点：-10cm, -5cm, 0cm, +5cm, +10cm（相邻点相距 5cm，中心点为 0cm）。
* 程序根据小球中心像素 cx 所在的区间做分段线性插值，准确换算出小球相对导轨中心的实际物理距离 `pos_mm`。
* 屏幕上实时画出各标定刻度线，方便每次上电时快速对准镜头和检查标定。

### 3.3 串口通信协议
通过 UART1 每 25ms（约 40Hz）向 H750 发送一次数据：
* **检测到小球**：`T,cx,cy,dx,dy,w,h,pos_mm\n`
  * `cx, cy`：检测框中心像素
  * `dx, dy`：相对图像中心的像素偏差
  * `w, h`：检测框宽高
  * `pos_mm`：标定后的实际物理距离（毫米）
* **丢失目标**：`N\n`

## 4. 运行效果
* 在开启摄像头采集、YOLO 模型推理和 LCD 屏幕 OSD 绘制全流程下，运行帧率稳定在 35~40 FPS。
* 从图像采集到串口发出的延迟在 30ms 以内，满足导轨快速动态平衡的要求。
