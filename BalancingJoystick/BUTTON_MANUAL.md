# 单轴步进平衡板 按键操作说明书

本说明书为您详细梳理了按键 K1 ~ K6 的全部功能。系统会根据当前处于的不同模式（如待机、运行中、调试等），对部分按键赋予不同的功能。

---

## 1. 基础全局按键 (任何模式下大部分时间有效)

| 按键 | 功能说明 | 适用场景 / 遇到什么问题时按它 |
| :--- | :--- | :--- |
| **K1** | **IMU 零点校准** | 当板子放置在绝对水平的桌面上，准备开机校准姿态，或长时间运行后发现陀螺仪（MS901M）零点发生明显漂移时按下。 |
| **K2** | **启动标准动作序列** | 开始运行规定动作（如前往 +5cm 处，随后前往 -5cm 处并保持）。 |
| **K3 (短按)** | **全局回中 / 急救复位** | **最常用的急救按键。** 当小球剧烈震荡、失控、或者您想打断当前一切动作让小球立刻回到正中心稳定时，短按 K3。 |
| **K3 (长按1秒)** | **进入/退出 前馈参数调试界面** | 当发现由光电管触发的起步/刹车动作不够平滑，需要调节前馈步数或时间时，长按进入专用调参界面。 |
| **K4** | **紧急停止 / 失能** | 遇到严重失控或想立刻停止电机转动（电机断电失去扭矩）时按下。再次按下可复位状态。 |
| **K5** | **手动目标微调 (+1cm)** | 在稳定平衡模式下，强制让小球的目标位置向正方向移动 1cm。 |
| **K6** | **手动目标微调 (-1cm)** | 在稳定平衡模式下，强制让小球的目标位置向负方向移动 1cm。 |

---

## 2. K2 模式专属微调 (当处于 K2 动作序列运行时)

在 K2 动作（前往左右指定位置）执行期间，K1 和 K4 被临时赋予了**机械偏置微调**的功能。

- **K1**：同时增加去往两侧的偏置步数（加绝对值，让板子翘得更高一点）。
- **K4**：同时减少去往两侧的偏置步数（减绝对值，让板子动作收敛一点）。
- *使用场景*：如果发现 K2 动作跑不到指定位置（偏软），就按 K1 增加偏置；如果冲得太猛，就按 K4 减少偏置。

---

## 3. K3 回中模式专属微调 (当小球处于稳定回中状态时)

在短按 K3 触发小球回中保持的过程中，K1 和 K4 被赋予了**中心点机械偏置微调**的功能。

- **K1**：减小 K3 模式下的基础机械偏置。
- **K4**：增加 K3 模式下的基础机械偏置。
- *使用场景*：如果发现短按 K3 后，小球停留在中心偏左或偏右，始终有几毫米的静态误差，就可以通过 K1/K4 进行补偿调节。屏幕第一行会显示 `K3 10cm OFF:xxx`。

---

## 4. 前馈参数调试界面 (长按 K3 触发)

长按 K3 一秒后，屏幕会切换到 4 行参数的调试界面。此时各按键功能完全改变，专用于参数修改：

| 按键 | 在调试界面的功能 |
| :--- | :--- |
| **K1** | **翻页**。在 `第一页（Start起步前馈）` 和 `第二页（Stop/End结束前馈）` 之间切换。 |
| **K4** | **移动光标**。屏幕右侧会有一个 `<` 符号，每按一次 K4，光标会在 4 行参数之间向下移动一行。 |
| **K5** | **数值增加**。若光标在步数行（S/ES），每次增加 `5` 步；若在时间行（T/ET），每次增加 `50ms`。 |
| **K6** | **数值减少**。若光标在步数行，每次减少 `5` 步；若在时间行，每次减少 `50ms`（时间最小为 0）。 |
| **长按 K3** | **保存并退出**，同时会触发一次 K3 全局回中，让新参数立刻在实战中生效。 |

---

## 5. 常见问题急救指南 (Q&A)

> [!CAUTION]
> **Q: 小球突然疯狂震荡，电机发出刺耳声音，怎么救？**
> **A:** 立刻按 **K4**！这会直接切断电机输出（失能），防止损坏机械结构。或者短按 **K3**，强制系统进入最稳定的回中状态。

> [!TIP]
> **Q: 开机后发现板子明明是平的，但小球一直往一边跑？**
> **A:** 把小球拿开，确认板子完全水平静止，按下 **K1** 重新校准 IMU 零点。

> [!NOTE]
> **Q: K2 动作到达两侧端点时，小球停不住，往前冲或者往回掉？**
> **A:** 这说明 K2 动作的偏置不够或太多。在它运行的过程中，通过 **K1** 和 **K4** 直接增加或减少偏置，直到小球能稳稳停住。

> [!IMPORTANT]
> **Q: 经过光电门瞬间，板子猛地颠簸了一下或者动作太肉（慢半拍）？**
> **A:** 长按 **K3** 进入调试模式。根据是起步（Start）还是结束（End），以及是 PA8 还是 PA11，用 **K4** 选定那一行。颠簸说明步数太大（用 **K6** 减），肉说明步数太小（用 **K5** 加），调完后再次长按 K3 退出即可立刻测试。
