# 平衡与主控部分 (BalancingJoystick)

## 1. 模块简介
负责导轨姿态控制和小球平衡，主控使用 STM32H750VBT6（480MHz，CubeMX + HAL 库）。
通过串口接收 K230 传来的小球位置，运行闭环 PID 控制步进电机调节导轨倾角；同时监听底盘的 2 个 GPIO 信号，在底盘起步和刹车时直接叠加工况前馈步数。

## 2. 硬件接口
* **步进电机**：张大头闭环步进电机。PB4 输出 STEP 脉冲，PE0 控制 DIR 方向，PB8 控制 EN 使能；USART3（115200）用于发送驱动器使能、失能和回零指令。
* **底盘状态输入**：PA8、PA11 两个 GPIO 输入引脚，直接接寻迹底盘单片机，用于同步底盘的起步与刹车动作。
* **视觉通信**：USART2（115200），接收 K230 发送的小球实时位置。
* **OLED 显示**：I2C 接口 0.96 寸 OLED，显示当前目标、球位置、前馈量与电机步数。
* **按键**：PE3（回零与启动平衡）、PC5 等。

## 3. 控制逻辑与前馈实现

### 3.1 小球位置闭环 (PID)
* 串口接收 K230 的小球毫米位置 `pos_mm`（中心为 0mm）。
* 计算位置偏差和速度估计，通过分段比例与微分计算电机目标倾角，把小球稳定在导轨中心 ±1cm 范围内。
* 软件限位：电机目标角度限制在 ±20° 以内，防止导轨撞击机械限位。

### 3.2 底盘加减速前馈（为什么改用 IO 通信）
小车在起步加速和到线刹车时，惯性会瞬间把球甩出去。
* **实际调试情况**：原先尝试装陀螺仪/加速度计测小车加速度做前馈，但实车跑起来后机械震动非常大，读出来的加速度波形全是毛刺，加重滤波后延迟又太大，根本来不及给电机补偿。
* **最终实现方案**：直接让寻迹底盘在起步提速和检测到终点刹车时翻转 PA8 / PA11 引脚电平。平衡板检测到引脚跳变沿后，立刻触发一个 500ms 内线性衰减的前馈步数：
  * 起步触发：目标步数补偿 -170 步（导轨前倾抵消启动惯性）；
  * 刹车触发：目标步数补偿 +55 步（导轨后仰抵消刹车冲力）；
  * 补偿值在 500ms 内按时间线性衰减回 0。
* 前馈参数通过实车反复跑圈一点点试出来写死，动作响应零延迟，完全避开了传感器震动干扰。

## 4. 任务时序设计
由 TIM6 提供 1ms 系统时基，在主循环中做分频轮询调度：
* **1ms 任务**：步进脉冲发生与推进、按键扫描、PA8/PA11 跳变沿检测与前馈衰减倒计时。
* **20ms 任务 (50Hz)**：解析 K230 数据包、计算小球 PID 闭环、叠加前馈补偿、更新电机目标步数。
* **200ms 任务**：刷新 OLED 显示屏数据。
* **1000ms 任务**：板载 LED 状态翻转。
