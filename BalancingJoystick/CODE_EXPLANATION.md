# H750 单步进滚球控制工程说明

生成日期：2026-07-31  
目标工程：`H750_single_stepper_board`  
主控芯片：STM32H750VBT6  
开发环境：STM32CubeMX + Keil MDK-ARM

## 1. 工程目标

本工程用于车载平衡滚球运动控制系统的单轴摆杆/水管控制。系统通过步进电机改变水管倾角，使钢球在水管轴向移动或稳定在目标位置附近。当前工程保留了赛题第三问的独立控制逻辑，并加入了 MS901M 姿态/加速度数据，用于稳定和前馈补偿。

系统核心思路是：

- K230 摄像头识别钢球位置，并通过串口发送球相对中心的毫米值。
- STM32H750 接收视觉位置，计算球的位置误差和速度。
- MS901M 通过串口输出姿态角和加速度，提供水管姿态反馈与小车加速度前馈。
- STM32 输出 STEP/DIR 脉冲控制张大头步进电机，串口命令保留用于驱动器使能、失能、回零等动作。
- OLED 显示当前通信、零点、误差、前馈和运行状态。

| 模块 | STM32 外设/引脚 | 用途 |

## 3. 时钟与节拍

系统时钟使用 25 MHz 外部晶振，通过 PLL 配置到 480 MHz。TIM6 作为 1 ms 系统节拍，采用“计次分频”方式在定时中断/周期任务中执行控制逻辑：

- 1 ms：按键扫描、步进电机脉冲推进、LED 计时。
- 20 ms：视觉/稳定控制环计算。
- 200 ms：OLED 刷新。
- 1000 ms：正常运行 LED 翻转。

这种结构减少了 `while` 中的复杂逻辑，使控制时序更稳定。

## 5. MS901M 通信

MS901M 使用 USART1，波特率 115200。驱动解析格式为：

```text
55 55 ID LEN DATA SUM
```

当前支持两类数据帧：

- `ID = 0x01, LEN = 6`：欧拉角 roll、pitch、yaw。
- `ID = 0x03, LEN = 12`：加速度 XYZ + 角速度 XYZ。

初始化时向 MS901M 发送配置命令，使其输出姿态角与加速度/角速度，并设置 50 Hz 输出频率。主控主要使用：

- 姿态角：用于水管调平和角度稳定。
- 选定轴加速度：用于小车加速度前馈补偿。当前配置使用 MS901M 的 Y 轴加速度，因为水管轴向与 901 的 Y 轴平行。

## 6. 控制逻辑

### 6.1 开机状态

复位后电机默认失能，驱动器处于可以手动转动的状态。程序会通过 EN 引脚和串口失能命令释放电机，避免上电后机械结构突然动作。

### 6.2 K1 流程

按下 K1 后执行：

1. 使能电机。
2. 发送回零命令，使水管回到机械零点附近。
3. 等待回零完成。
4. 采集 MS901M 当前姿态角作为角度零点。
5. 采集 MS901M 当前轴向加速度作为加速度零点。
6. 进入中心稳定模式。

### 6.3 位置闭环

K230 发送球位置后，STM32 得到球相对中心的毫米误差。控制中使用位置误差、速度估计、预测误差和限幅逻辑，生成电机目标倾角。目标是让钢球尽量不离开中心 1 cm 范围。

### 6.4 加速度前馈

当前版本不再使用 ICM42688。前馈改为使用 MS901M 加速度：

```text
前馈倾角约等于 轴向加速度 / 重力加速度
```

代码中先减去 K1 清零时记录的加速度零点，再换算成步进电机目标步数。这样当小车前后加速时，水管可以提前倾斜，用来抵消钢球受到的惯性影响。

### 6.5 软件限位

电机目标角受到软件限位保护，当前测试限位为正负 20 度。所有视觉闭环、姿态稳定和前馈补偿最终都会经过统一限幅，避免机械结构过度倾斜。

## 7. OLED 状态含义

常见显示内容：

| 显示 | 含义 |
| --- | --- |
| `MS901 ANG WAIT` | 没有收到新的 MS901M 姿态角帧 |
| `MS901 ACC WAIT` | 没有收到新的 MS901M 加速度帧 |
| `ZERO xx/50` | 正在采集零点 |
| `RUN Pxxxxx` | 稳定模式运行中，显示当前电机位置 |
| `Mxxxxx Axxxx` | `M` 为加速度误差 mg，`A` 为前馈输出步数 |
| `MS901 RX OK` | MS901M 角度和加速度通信正常 |

## 8. K230 数据格式

K230 通过 USART2 发送一行文本数据。STM32 从中解析目标中心、框大小和标定后的毫米位置，核心控制量是球相对水管中心的 `pos_mm`。视觉标定中，水管中心为 0 mm，左右黑点间距对应 5 cm，用于把像素坐标换算成厘米/毫米位置。
