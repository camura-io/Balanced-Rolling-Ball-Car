# 寻迹底盘部分 (LineTracking)

## 1. 模块简介
负责小车底盘的电机驱动、红外循迹和运行状态切换，主控使用 STM32F103C8T6（72MHz，标准库）。

## 2. 硬件连接
* **循迹传感器**：8 路红外循迹板（I2C 接口，PB10=SCL，PB11=SDA）。
* **电机驱动**：直流减速电机 + TB6612 驱动，Timer3 输出 PWM（`pwm.c`）。
* **编码器**：左右两路正交编码器，接 Timer2 和 Timer4（`encoder.c`）。
* **OLED 显示**：0.96 寸 I2C OLED（PB8=SCL，PB9=SDA），显示当前模式、车速、里程与运行时间。
* **按键**：PB12（切换模式）、PB13（确认启动）。
* **状态同步输出**：预留 2 个 GPIO 连接到平衡主控板（H750），在起步加速和减速时翻转电平做前馈触发。

## 3. 控制算法与逻辑

### 3.1 红外传感器加权计算
传感器共有 8 路探头，黑线返回 0。对触发探头按位置分配权重（-7, -5, -3, -1, 1, 3, 5, 7），计算加权平均值作为小车的横向偏差量 Error：
* 偏差计算公式：`Error = (触发探头的权重之和) / 触发探头数`
* 相比单点开关量判断，加权平均输出的位置偏差更连续、平滑。

### 3.2 分段变增益 PD 控制
* **死区处理**：偏差绝对值小于 0.3 时 Kp=0，避免直道上微小抖动引起电机反复调速。
* **小偏差（直道）**：偏差在 0.3~1.5 之间使用较小 Kp（1.5），保证车身平稳。
* **大偏差（弯道）**：偏差大于 1.5 时切换为较大 Kp（2.38），提供足够的差速快速过弯。
* **低通微分 Kd**：对偏差做一阶低通滤波后求导，抑制入弯和出弯时的车头摆动。
* **车速自适应缩放**：差速输出乘以 `(当前车速 / 标称车速)`，换用不同巡航车速时无需重新整定 PID。

### 3.3 斜坡调速与状态机
* **梯形加减速**：起步时按 10ms 周期步进提速到目标车速（如 25cm/s），到达终点前检测到停止线后按固定步长减速停车，防止急起急停打滑。
* **脱轨保护**：如果 8 路探头全部丢线，保持最后一次看到的偏差方向低速打方向自旋找线；若超过 80ms 仍未找到黑线则直接关停电机。
* **时间片轮询**：基于 Timer1 的 10ms 定时器作为系统主节拍，消除阻塞延时。
